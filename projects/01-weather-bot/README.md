# 🌤️ Weather Bot (n8n + AI)

> Автоматический погодный бот с AI-синоптиком и записью истории в PostgreSQL.

## 🎯 Задача
Автоматически отслеживать погоду в заданном городе по расписанию, сохранять историю в базу данных и отправлять креативные уведомления в Telegram.

## 🛠️ Стек
- n8n
- Open-Meteo API
- PostgreSQL
- AI Agent (Ollama/OpenAI)
- Telegram Bot API

## 📊 Статус проекта
🚧 **В разработке (Рефакторинг V1 -> V2)**.
Цель: исправить ошибки, добавить обработку ошибок, убрать хардкод и настроить идемпотентность.

## ⚙️ Как запустить (V2)
1. Создать таблицу в PostgreSQL с помощью `schema.sql`.
2. Импортировать `workflow.json` в n8n.
3. Настроить переменные окружения (см. `.env.example` в корне репозитория).
